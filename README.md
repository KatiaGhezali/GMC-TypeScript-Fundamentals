# TypeScript Slack Bot

A simple Slack bot built with TypeScript, Node.js, and Slack Bolt. This project was created as part of the GMC TypeScript Fundamentals checkpoint.

## Features

- Responds to the `/hello` slash command.
- Listens for messages in Slack channels and logs their content to the terminal.
- Uses Slack Socket Mode to connect without requiring a public server URL.
- Loads Slack credentials from environment variables.

## Tech Stack

- TypeScript
- Node.js
- Slack Bolt
- dotenv
- Slack Events API
